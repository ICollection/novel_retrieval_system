# 系统配置说明

配置文件为 `service/internal/config/config.yaml`，采用 YAML 格式，分为 `station`、`models`、`postgres`、`qdrant`、`minio` 五段。

## 1. 加载方式

- 通过 `//go:embed config.yaml` 在编译期把配置文件内容嵌入二进制（`config/init.go`），运行时不读取外部文件；
- `config` 包的 `init()` 用 viper 解析嵌入内容并填充 `Config` 结构体，解析失败直接调用 `log.Fatal` 终止进程；
- 解析结果保存在全局变量 `config.Cfg`，其它包通过 `config.Cfg.XXX` 读取；
- 三个模型的密钥支持环境变量回填：配置中 `key` 为空时，分别取 `NOVEL_EMBED_KEY`、`NOVEL_LARGE_KEY`、`NOVEL_SMALL_KEY`。

## 2. 结构总览

```
station   站点服务与登录令牌
models    模型服务（OpenAI 兼容接口）
  embed   向量模型
  large   大语言模型
  small   小语言模型
postgres  PostgreSQL 数据库
qdrant    Qdrant 向量数据库
minio     MinIO 对象存储
```

## 3. 各段说明

### 3.1 station（站点服务）

| 字段 | 类型 | 单位 | 说明 |
| :--- | :--- | :--- | :--- |
| `port` | int | — | HTTP 监听端口（`main.go` 中绑定 `0.0.0.0:port`） |
| `context_path` | string | — | 接口路径前缀，各 handler 以 `context_path + "/模块名"` 分组注册路由 |
| `mode` | string | — | Gin 运行模式，取值 `debug` / `release` / `test`，main 启动时据此设置 |
| `secret` | string | — | 登录令牌的 HMAC-SHA256 签名密钥，签发与校验共用 |
| `expire` | int | 小时 | 登录令牌有效期，签发时按此设置过期时间 |
| `concurrency` | int | 个 | 同时处理的小说任务数量，调度器达到该值后不再取新任务 |
| `abstract` | bool | — | 是否在向量化时为分片生成摘要并写入摘要向量 |

### 3.2 models（模型服务）

三段结构相同，均为 OpenAI 兼容接口：

| 字段 | 类型 | 单位 | 说明 |
| :--- | :--- | :--- | :--- |
| `address` | string | — | 接口地址，需包含版本路径（如 `/v1`） |
| `name` | string | — | 模型名称 |
| `key` | string | — | 接口密钥，为空表示无需认证（可用环境变量回填） |
| `timeout` | int | 秒 | 单次请求超时 |

三段与代码中的客户端的对应关系：

| 配置段 | 客户端变量 | 用途 |
| :--- | :--- | :--- |
| `models.embed` | `VEM` | 文本向量化（分片、摘要、用户问题） |
| `models.large` | `LLM` | 最终回答（流式输出） |
| `models.small` | `SLM` | 检索问题整理、历史对话压缩、分片摘要 |

### 3.3 postgres（数据库）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `host` | string | 服务地址 |
| `port` | int | 服务端口，默认 5432 |
| `username` | string | 登录名 |
| `password` | string | 登录密码 |
| `database` | string | 数据库名称 |
| `sslmode` | string | SSL 模式，取值 `disable` / `require` |
| `timeout` | int | 操作超时（秒） |

以上字段由 `GetDSN()` 拼接为连接串：`postgres://用户名:密码@地址:端口/库名?sslmode=模式`，连接池在 `storage.Initialize` 中创建。

### 3.4 qdrant（向量数据库）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `host` | string | 服务地址 |
| `port` | int | gRPC 端口，默认 6334 |
| `api_key` | string | 接口密钥，未开启鉴权时留空 |
| `collection` | string | 集合名称，启动时若不存在则自动创建 |
| `timeout` | int | 操作超时（秒） |

集合结构在 `CreateCollection` 中定义：稠密向量 `original`、`abstract`（1024 维、Cosine、Float16），稀疏向量 `matching`（BM25，启用 idf 修正）。

### 3.5 minio（对象存储）

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `endpoint` | string | 服务地址，不含协议与端口 |
| `port` | int | 服务端口，默认 9000 |
| `access_key` | string | 登录名 |
| `secret_key` | string | 登录密码 |
| `bucket` | string | 存储桶名称 |
| `use_ssl` | bool | 是否使用 HTTPS |
| `region` | string | 区域，MinIO 默认为 `us-east-1` |
| `timeout` | int | 操作超时（秒） |

桶内按对象名前缀区分两类文件：

| 前缀 | 内容 |
| :--- | :--- |
| `Origin` | 用户上传的原始文件（`文件编码.扩展名`） |
| `Normal` | 归一化后的 Markdown 文档（`文件编码.md`） |

## 4. 嵌入的提示词

以下文件与 `config.yaml` 位于同一目录，同样通过 `//go:embed` 嵌入，作为全局字符串常量提供给业务层：

| 文件 | 变量 | 用途 |
| :--- | :--- | :--- |
| `recall.txt` | `config.Recall` | 整理检索问题（召回前由小模型改写） |
| `normal.txt` | `config.Normal` | 最终回答的系统提示词（大模型） |
| `compress.txt` | `config.Compress` | 历史对话压缩（小模型） |
| `abstract.txt` | `config.Abstract` | 分片摘要生成（受 `station.abstract` 控制是否使用） |
